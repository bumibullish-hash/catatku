Tentang CatatKu

Aplikasi web untuk mencatat tugas dan catatan kuliah di satu tempat.

Yang bisa dilakukan

  • Menambah, mengedit, dan menghapus tugas, serta menandainya selesai.
  • Mencari tugas, lalu menyaringnya berdasarkan status dan prioritas.
  • Menulis catatan berwarna: tambah, edit, hapus, dan cari.
  • Melihat jumlah tugas, deadline terdekat, dan jumlah catatan di beranda.

Cara kerjanya

Halaman di browser mengirim permintaan ke server Node.js. Server membaca dan menyimpan data ke database MongoDB, lalu mengirim hasilnya kembali ke halaman.

Browser Server Node.js MongoDB

Teknologi yang digunakan

HTMLStruktur semua halaman.
CSSTema warna, tipografi, dan penyesuaian tampilan di atas Bootstrap.
Bootstrap 5Navbar, grid responsif, modal, form, dan notifikasi.
JavaScriptMengambil dan mengirim data ke server, menampilkan daftar, mencari, menyaring, dan memeriksa isian form.
Node.js dan ExpressMenjalankan server dan menyediakan API untuk tugas dan catatan.
MongoDB dan MongooseMenyimpan data tugas dan catatan di database MongoDB, dihubungkan ke server lewat Mongoose.
